Как было

Самописный гейт перестал вывозить

1 · ОДИН ЧЕЛОВЕК

Новый человек — правка кода

Гейт знал одного пользователя. Дать техлиду только отчёты значило дописать гейт и завести ещё одну куку.

2 · НЕТ ПРОТОКОЛА

Приложения не умели «войти через»

Grafana и другие сервисы с OIDC могли получить только куку гейта — нормального единого входа не было.

3 · ИНЦИДЕНТ

Учётка жила в файлах

Перенос гейта под другого пользователя сгенерировал новые секреты, и вход лежал до ручного восстановления. Журнал входов — только текст в системном логе.

4 · ЗООПАРК

У каждой интеграции свой механизм

Агенты — по подписи, коннектор ИИ — свой OAuth поверх гейта, люди — кука. Три механизма и ноль общей диагностики.

Как встроен

Каждый запрос сначала спрашивает Authentik

Браузероткрывает отчёт, виджет или страницу согласия ИИ-коннектора
→
nginx серверадо приложения — подзапрос «можно ли?» (auth_request)
→
Caddy коробкиспрашивает outpost Authentik и сверяет группу с приложением
→
Authentikсессия, второй фактор, группы человека
401сессии нет — nginx уводит на вход Authentik и после входа возвращает на ту же страницу
403вошёл, но нет группы этого приложения — страница «нет доступа», а не пустой экран
200можно; в ответе — логин и группы, приложение знает, кто пришёл

Приложения ничего не знают о паролях и втором факторе: это схема forward-auth. Новое приложение за входом — одна строка в конфиге, а не код.

Защита от подделки

Свою группу не подставишь

  • Заголовки «кто вошёл» клиента обнуляютсяnginx и мост стирают X-Authentik-Username и X-Authentik-Groups из запроса; их ставит только outpost
  • Приложение перепроверяет самостраница согласия ИИ-коннектора повторно спрашивает Authentik — на случай, если кто-то обойдёт nginx изнутри сервера
  • Наружу слушает только nginxAuthentik, его база и Caddy привязаны к 127.0.0.1
  • Проверено тестомCI поднимает настоящие контейнеры: запрос с поддельным «poh-box-owners» в заголовке получает 403

ПРИМЕР · ТЕХЛИД

Видит отчёт спринта и больше ничего

Учётка в группах «доступ: sprints» и «доступ: business» (вкладки отчёта грузят обе) и «mcp: atlassian-read». Почта, агенты, сервер — 403. Дать или забрать — одна группа.

Группа приложения появляется вместе с приложением: генератор заводит её в Authentik сам. Решение по группе принимает Caddy, поэтому одна и та же проверка работает для людей, агентов и ИИ.

Конфигурация как код

Настройки входа живут в git

# box-settings — одна строка на решение BOX_AUTH_USERS=techlead:…:sprints+business +mcp-atlassian-read BOX_AUTH_NO_MFA=techlead BOX_AUTH_AGENTS=agent-news:news+linkshort BOX_MCP_PROFILES=full,atlassian-read # → генератор собирает blueprint Authentik: # группы, приложения, учётки, политики
  • Blueprint вместо кликовAuthentik применяет его сам; руками в интерфейсе такие учётки не правят — blueprint перепишет
  • Секретов в git нетпароли, токены агентов, ключи Authentik — в файле на сервере с правами 600
  • Каждая правка — PR и CICI поднимает Authentik, Caddy и заглушки и проверяет вход снаружи, как браузер
  • На сервер — только из mainобновлятор тянет fast-forward и откатывается при сбое; правка на сервере блокирует обновления

Второй фактор

Пароля мало — с одним исключением

ПО УМОЛЧАНИЮ

Ключ или код обязательны

Passkey (WebAuthn) или TOTP. Нет ни того, ни другого — Authentik заставит завести при первом входе.

ИСКЛЮЧЕНИЕ

Группа «вход: без второго фактора»

Для гостя в окне виджета мессенджера: passkey во фрейме может не сработать, TOTP — чужое устройство. Только логин и пароль.

FAIL CLOSED

Ошибка — фактор остаётся

Если политика исключения сломается, второй фактор не пропадёт у всех. Оба конца проверяет CI: гостю — без фактора, владельцу — с ним.

Учётка без второго фактора держится на одном пароле, поэтому она узкая по доступу и её пароль меняется после демонстрации. Вернуть фактор — убрать логин из одной строки настроек.

Агенты и сервисы

Агент — тоже учётка

СЕРВИСНЫЙ АККАУНТ

Токен вместо пароля

Агент входит заголовком Authorization с токеном приложения. У него свои группы — те же «доступ: <приложение>», что у людей: агент ленты видит ленту, но не почту.

ГРАНИЦА

Сначала подпись агента, потом человек

Где агенты ходили по подписи Ed25519, проверка идёт двумя ступенями: верная подпись — пропуск, иначе — обычный вход человека. Неверная подпись получает форму входа, а не доступ.

ОТЗЫВ

Отключить — в одном месте

Выключить учётку или забрать группу в Authentik — агент теряет доступ ко всем приложениям сразу.

ПРОВЕРЕНО

Свой — 200, чужой — 403

CI: агент со своим токеном открывает свои приложения, чужое — 403, неверный токен — 401.

  • Подключение — через вход AuthentikClaude получает доступ к коннектору только после согласия на странице за входом

Грабли эксплуатации

Чему мы научились

КРУГ ВХОДА

Форма появляется и исчезает

Почти всегда упал бэкенд за входом, а не Authentik. Сначала проверить сервис приложения, потом трогать вход.

ПРАВКА НА СЕРВЕРЕ

Обновления молча встали

Две правки входа сделали прямо на сервере — обновлятор по своей защите пропускал каждую выкладку несколько дней. Только PR и main.

ФРЕЙМЫ

Куки во фрейме мессенджера

Виджеты открываются в iframe, где куки входа могут считаться сторонними. Проверяли внутри мессенджера до переключения каждого виджета.

КИРИЛЛИЦА

«доступ: pi» в заголовке

Группы приходят сырыми байтами UTF-8, а Python читает заголовки как latin-1. Без перекодировки группа «не совпадает» — и человеку отказ.

Честно о границах

Что Authentik не решает

Права внутри приложения

ИИ-коннектор читает Jira от служебной учётки: техлид увидит всё, что видит она, а не только свои проекты.

Один сервер

Authentik — точка входа во всё. Упал он или память кончилась — не войдёт никто. Отсюда лимиты, бэкап и запасной путь восстановления.

Что делать после входа

Запись в Jira, сообщения людям, shell — помечены, и клиент спрашивает разрешение. Это дисциплина человека, а не блокировка.

Пароль без второго фактора

Исключение для гостей удобно, но держится на одном пароле. Компенсируем узким доступом и сменой пароля.

Дать доступ —
одна группа

Новый человек, агент или приложение — запись в настройках входа и PR. Забрать доступ — так же. Всё остальное делает Authentik.
